# Code of Conduct

ParkEase discussions, issues, and pull requests should be respectful and
focused on the project. Treat others with courtesy. Harassment, threats,
discrimination, personal attacks, and sharing another person's private
information without consent are not acceptable.

Maintainers may edit, hide, or remove content and restrict participation when
these standards are violated. Use GitHub's **Report content** option to flag
abusive comments. For other concerns, open an issue asking a maintainer for a
private contact channel without posting sensitive details.

These participation rules do not grant a license to use the project. See
[LICENSE](LICENSE).
