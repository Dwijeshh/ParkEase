# Contributing to ParkEase

ParkEase is a proprietary academic prototype. We welcome bug reports and
suggestions through GitHub Issues, but we are not accepting outside code,
documentation, or design contributions at this time. Please do not submit a
pull request unless a maintainer has invited you to do so.

When filing an issue, describe the observed behavior, steps to reproduce it,
and the expected behavior. Remove credentials, personal data, and other
sensitive information from screenshots and logs. Report vulnerabilities
privately as described in [SECURITY.md](SECURITY.md).

An invitation to contribute does not grant permission to use or distribute
ParkEase. Any contribution terms must be agreed with the maintainers before
work is submitted. See [LICENSE](LICENSE) for the project's rights notice.
