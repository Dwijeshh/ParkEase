# Security Policy

ParkEase is an academic prototype in active development. No released version
is currently supported with a guaranteed security update schedule.

Please do not disclose a suspected vulnerability in a public issue, pull
request, or discussion. If GitHub's private vulnerability reporting is
available for this repository, use **Security > Report a vulnerability**.
Otherwise, open a public issue asking a maintainer for a private reporting
channel, without including vulnerability details.

In a private report, include the affected component, steps to reproduce,
potential impact, and any suggested fix. Do not include real credentials or
personal data. The maintainers will review reports as capacity allows.
